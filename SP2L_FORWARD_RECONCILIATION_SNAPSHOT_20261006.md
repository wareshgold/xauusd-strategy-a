## 6. Critical open audit: ACT10 / TRAIL2 semantics

This is the **next technical gate**.

Before interpreting ACT10/TRAIL2 performance as meaningful evidence, verify independently:

1. **Unit definition**
   - MT5 symbol point is 0.01.
   - Current forward event evidence uses `pip_size=0.01` and `pip_method=POINT_FOR_NON_FX_DIGITS`.
   - Historical/config code also contains `XAU_PIP_SIZE_PRICE=0.1`.
   - This discrepancy must remain explicitly flagged until resolved by the experiment specification/source or a frozen research convention.

2. **Activation semantics**
   - Confirm exactly when ACT10 becomes active.
   - Confirm whether activation is measured from actual fill price, theoretical entry, or another frozen reference.

3. **Trail distance semantics**
   - Confirm whether TRAIL2 means 2 price-points, 2 XAU pips at 0.01, or another intended unit.
   - Do not infer this from profitable backtest ranking.

4. **Evaluation timing**
   - Current runner evaluates trailing from the latest completed M1 bar.
   - Tick-level bid/ask path is therefore not reconstructed exactly.
   - This is a known research limitation.

5. **Broker stop constraints**
   - The event journal contains `TRAIL_SKIP` with `BROKER_STOP_CONSTRAINT`.
   - These events are real broker constraints and must be measured, not silently treated as successful trail updates.

6. **Actual-vs-theoretical execution**
   - Candidate theoretical entry and actual MT5 fill can differ.
   - Any R calculation must state which price is authoritative.

Only after these semantics are frozen should ACT10/TRAIL2 be used as a clean statistical experiment.
