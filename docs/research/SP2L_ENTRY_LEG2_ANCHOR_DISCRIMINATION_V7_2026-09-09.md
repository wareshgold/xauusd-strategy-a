## A/B/C/D discrimination

### What the source confirms

The source explicitly uses the classical name **AB=CD / 2Leg**, and repeatedly describes a first leg followed by a second leg of comparable magnitude. The 45–55 examples continue to use this conceptual model.

### What the source does not confirm

The source does not assign textual labels A, B, C and D to the exact candle OHLC coordinates used in the demonstrated setups. Therefore the following common mapping is only a research hypothesis and must not be treated as canonical:

- A = beginning of Leg 1;
- B = end of Leg 1;
- C = correction / entry reference;
- D = projected end of Leg 2.

In particular, the source does not prove that C is:

- the first pullback Low/High;
- the latest Higher-Low/Lower-High;
- the start of Leg 2;
- a candle body edge;
- a wick extreme;
- or a Fibonacci retracement coordinate.

## Entry candidate decision

### Candidate 1 — first/relevant prior Low/High

**Evidence: strongest.**

The 45:15–46:36 section directly describes a three-candle situation where the next candle returns to the Low/High and the trade is taken from the first pullback. The 38:38–39:11 section elsewhere in the source independently describes correction as movement below the first Low and permits a pending Limit before the next candle completes.

This makes a structural prior Low/High the leading interpretation of the executable entry reference.

### Candidate 2 — latest Higher-Low / Lower-High

**Evidence: plausible but not uniquely established.**

The source repeatedly describes sequences of higher lows / lower highs and the visual examples can show the order reference moving with the developing structure. However, the teacher does not give a deterministic rule such as “always use the latest swing.”

### Candidate 3 — start of Leg 2

**Evidence: important structural reference, but not proven as Entry.**

53:43 explicitly says the pullback is coming to the beginning of Leg 2. 54:29 then describes a Buy Limit at the demonstrated level. This makes the start of Leg 2 highly relevant, but the language does not establish an identity relation `Entry = StartOfLeg2` for all setups.

### Candidate 4 — candle body edge / wick extreme

**Evidence: unresolved.**

The source emphasizes candle-level reading but does not provide a universal body/wick execution formula in this section.

### Candidate 5 — Fibonacci / percentage retracement

**Evidence: rejected as canonical for now.**

No source statement in the 45–55 section defines the executable Entry through a Fibonacci percentage. Classical AB=CD/Fibonacci treatment is explicitly contrasted earlier with the source's candle-level treatment.
