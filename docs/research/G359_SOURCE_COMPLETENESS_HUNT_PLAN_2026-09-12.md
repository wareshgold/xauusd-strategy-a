# G359 — Targeted Source Completeness Hunt

## Objective

Search only authoritative Poursamadi material for explicit resolution of executable geometry, without interpreting profitability as source evidence.

## Six blocked dimensions

1. P-GAP endpoint candle indices and OHLC fields.
2. Wick/body/open/close convention.
3. Minimum gap size, overlap and tolerance.
4. A/B/C/D anchor definitions and scale-selection rule.
5. Exact pending-limit/fill and SL semantics, including any offset.
6. TP1/TP2/R1/R2 mapping and scope of the public-page 1:1 default; status of the 50% secondary entry.

## Search order

1. Original full SP2L lesson and transcript.
2. Original gap lesson and its complete visual examples.
3. Official Poursamadi SP2L web material.
4. Other first-party Poursamadi educational material only if authorship/source provenance is explicit.

## Stop condition

If a source does not explicitly resolve a dimension, record it as unresolved. Do not manufacture a rule from chart pixels, generic trading conventions, or backtest performance.
