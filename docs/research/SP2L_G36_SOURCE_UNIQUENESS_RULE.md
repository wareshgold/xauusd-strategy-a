# G36 Source-Uniqueness Rule

A geometry is not canonical merely because it is plausible, conventional, simple, or profitable.

For each unresolved blocker:

1. Collect direct source frames and transcript evidence.
2. Enumerate only interpretations compatible with the evidence.
3. Use synthetic fixtures to reject interpretations that contradict explicit source behavior.
4. If exactly one interpretation remains source-consistent, it may be promoted to a candidate for Frozen Geometry review.
5. If two or more interpretations remain source-consistent, retain `UNRESOLVED`.
6. Never use historical profitability to break a source tie.
7. Never introduce an unobserved tolerance, buffer, threshold, anchor, candle-index convention, or execution shortcut to force uniqueness.

This rule is binding for P-Gap, Entry, SL, Trigger, AB=CD, Leg2/TP and pending-order replacement.
