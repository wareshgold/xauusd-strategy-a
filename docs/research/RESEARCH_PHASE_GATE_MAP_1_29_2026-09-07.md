## Legend

| Mark | Meaning |
|---|---|
| **SOURCE-ALIGNED** | Grounded in the preserved Poorsamadi source (semantic authority) or the Knowledge Map's own gates. |
| **DESCRIPTIVE-ONLY** | Statistical forensics on the **legacy close-reclaim baseline**; self-labeled descriptive, no promotion, no production change, Fresh Holdout locked. Legitimate as a "before" reference, not canonical strategy progress. |
| **OUT-OF-GATE-ORDER** | Performs a later Knowledge-Map progression step (robustness / stability / validation) **before** the canonical geometry is frozen — G4 (Leg 1 endpoints) and G5 (Leg 2 origin) are still `TBD / VISUAL SOURCE REQUIRED`. Valid as legacy-baseline diagnostics, invalid as canonical SP2L progress. |

The Knowledge Map's progression gate is: `SOURCE RESOLUTION → synthetic fixtures → frozen candidate geometry → DEV → untouched VAL → robustness/stability → Fresh Holdout → production`.
