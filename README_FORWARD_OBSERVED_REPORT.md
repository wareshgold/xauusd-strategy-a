# Forward Observed Research Report

The Factory Forward evidence boundary now has a deterministic report contract:

`Forward lifecycle → immutable observed evidence → observed descriptive statistics → deterministic report`

The report is research-only and provenance-bound. It records observed lifecycle facts,
reconciliation identity, pips/net coverage and descriptive uncertainty.

It deliberately does **not**:

- derive R-multiples;
- define canonical win/loss semantics;
- select parameters;
- optimize;
- promote Strategy A;
- authorize production BUY/SELL decisions.

The R/statistical boundary remains fail-closed until an explicit, source-confirmed
trade-return mapping is supplied.
